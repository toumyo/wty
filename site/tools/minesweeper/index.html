掃雷

經典掃雷，打開就能玩。有簡單、中等、困難三種難度，畫面上會顯示計時與剩餘地雷數。

打開工具 →

免費 · 免註冊 · 瀏覽器直接使用 · 介面語言：簡體中文 · 作者：Taiyang Wang

功能

  • 簡單、中等、困難三種難度
  • 計時器與剩餘地雷數
  • 一鍵重新開始
  • 瀏覽器直接玩，無需下載

使用方法

  1. 選擇難度
  2. 點擊格子翻開，數字代表周圍八格中的地雷數
  3. 翻開所有安全格子即獲勝

常見問題

規則是什麼？

翻開的數字表示周圍八格中有幾顆地雷。根據數字推理，避開地雷，翻開所有安全的格子就贏了。
