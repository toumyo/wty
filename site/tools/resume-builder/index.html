AI 簡歷製作

選一個模板，填好內容，再用 AI 自動翻譯成日文與英文版本。適合在日本或海外找工作時使用。

打開工具 →

免費 · 免註冊 · 瀏覽器直接使用 · 介面語言：中文、日文、英文 · 作者：Taiyang Wang

功能

  • 50 多個模板，分為極簡、商務、科技、創意、高管、國際等類別
  • 姓名、聯絡方式、自我介紹、技能、工作經歷、學歷、證照等欄位，也可以自訂欄位
  • AI 自動翻譯成日文與英文，以分頁切換
  • 列印或存成 PDF
  • 支援 Anthropic Claude、Google Gemini、DeepSeek 的 API Key

使用方法

  1. 選擇模板
  2. 填寫簡歷內容
  3. 設定自己的 AI API Key，產生日文與英文版本
  4. 列印或存成 PDF

常見問題

需要付費嗎？

工具本身免費。AI 翻譯需要使用你自己的 API Key，費用由對應的 AI 服務商依用量收取。

API Key 安全嗎？

依工具說明，API Key 以 AES-256 加密，只在你的瀏覽器內處理，不會上傳到伺服器；清除瀏覽器資料後就會刪除。

可以做日文履歷嗎？

可以。填好內容後，能自動翻譯成日文與英文版本。
