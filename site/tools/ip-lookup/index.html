使用方法

常見問題

顯示的位置準確嗎？

IP 定位只能看到大致的地區，不代表你的確切地址。

為什麼位置和我實際所在地不同？

如果你使用 VPN、代理或某些行動網路，顯示的會是出口伺服器的位置。
