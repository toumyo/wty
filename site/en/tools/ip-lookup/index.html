  • Powered by Cloudflare's edge network

How to use

  1. Open the page
  2. Wait for it to load, then read your IP and location

FAQ

How accurate is the location?

IP geolocation only shows a rough area, not your exact address.

Why does it show a different place from where I am?

If you use a VPN, a proxy or some mobile networks, you will see the location of the exit server.
