AI Résumé Builder

Pick a template, fill it in, and let AI create Japanese and English versions. Useful when job hunting in Japan or abroad.

Open the tool →

Free · No sign-up · Runs in your browser · Interface language：Chinese, Japanese, English · Built by：Taiyang Wang

Features

  • 50+ templates: minimal, business, tech, creative, executive and international
  • Sections for contact details, summary, skills, experience, education and certificates, plus custom sections
  • AI auto-translation into Japanese and English, shown in tabs
  • Print or save as PDF
  • Works with Anthropic Claude, Google Gemini and DeepSeek API keys

How to use

  1. Choose a template
  2. Fill in your résumé
  3. Add your own AI API key to generate Japanese and English versions
  4. Print or save as PDF

FAQ

Is it free?

The tool is free. AI translation uses your own API key, so the AI provider bills you for usage.

Is my API key safe?

According to the tool, your key is encrypted with AES-256 and handled only in your browser, never uploaded to a server. Clearing your browser data deletes it.

Can it make a Japanese résumé?

Yes. It can translate what you write into Japanese and English versions.
